TILT UPDATE 1.0.2  (email verification removed)

STEP 1: FIREBASE (do this first, it is required)
  Firebase console > your Tilt project > Build > Realtime Database > Rules tab.
  Ctrl+A, Delete. Open database.rules.json (in this folder) in Notepad, Ctrl+A, Ctrl+C,
  paste into Firebase, click Publish.

STEP 2: GITHUB
  github.com > your tilt repository > Add file > Upload files.
  Drag in index.html, package.json and database.rules.json from this folder.
  Click Commit changes.

STEP 3: RELEASE
  Releases > Draft a new release > Choose a tag > type v1.0.2 > Create new tag > Publish release.
  Wait for Actions > Build Tilt to turn green (about 10 minutes).
  Releases > v1.0.2 has Tilt-Setup-1.0.2.exe. Installed apps update themselves on next open.
